Mājasdarbu plānotājs

Mobilās lietotnes tīmekļa prototips, izstrādāts atbilstoši PPS v1.0.0.

Par projektu
“Mājasdarbu plānotājs” ir lietotne, kas palīdz skolēniem organizēt mājasdarbus, sekot termiņiem un pārvaldīt progresu.

---

Palaišana
Atver failu `index.html` pārlūkprogrammā.  
Nav nepieciešams serveris vai papildu instalācija.

---

Failu struktūra

majasdarbu-planotajs/
├── index.html
├── style.css
├── script.js
└── README.md

---

Funckijas

| ID | Funkcija |
|----|----------|
| H1 | Pievienot mājasdarbu |
| H2 | Norādīt datumu un laiku |
| H3 | Skatīt mājasdarbus |
| H4 | Atzīmēt kā izpildītu |
| H5 | Dzēst mājasdarbu |
| H6 | Filtrēt mājasdarbus |
| H7 | Noteikt prioritāti |
| H8 | Skatīt progresu |

---
Datu glabāšana
Dati tiek saglabāti `localStorage`, tādēļ tie paliek saglabāti arī pēc lapas pārlādēšanas.

Izmantotās tehnoloģijas

- localStorage
